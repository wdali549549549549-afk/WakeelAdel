# وكيل عادل — Android v1

نسخة أولية عربية لتطبيق وكيل ذكاء اصطناعي.

## الموجود
- واجهة عربية.
- أوامر كتابية.
- أوامر صوتية.
- أساس صلاحيات الصوت وجهات الاتصال والمكالمات.
- GitHub Actions لبناء APK تلقائياً.

## بناء APK من الهاتف فقط
1. أنشئ مستودعاً خاصاً في GitHub.
2. ارفع كل ملفات هذا المشروع إلى المستودع، بما فيها `.github/workflows/build.yml`.
3. افتح تبويب **Actions**.
4. اختر **Build APK** ثم **Run workflow**.
5. بعد نجاح البناء افتح تشغيل الـworkflow.
6. من قسم **Artifacts** نزّل `Wakeel-Adel-debug-apk`.
7. فك الضغط عن ملف الـartifact وستجد `app-debug.apk`.
8. افتح APK على هاتف أندرويد وثبّته. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

> هذه نسخة Debug للتجربة وليست إصداراً منشوراً على Google Play.
